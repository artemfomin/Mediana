# Политика безопасности

## Поддерживаемые версии

| Версия | Статус |
|---|---|
| 1.0.x | активная поддержка |
| < 1.0 | не поддерживается |

## Как сообщить об уязвимости

**Не создавайте публичный issue для уязвимостей.**

1. Напишите приватно через [GitHub-профиль владельца](https://github.com/artemfomin) с темой `[SECURITY] Mediana` — опишите проблему, затронутые пакеты/версии, шаги воспроизведения или PoC.
2. Ответ — в течение 72 часов; оценка и план — до 7 дней.
3. Координированное раскрытие: фикс выходит релизом, после чего открывается публичный advisory (GitHub Security Advisory + публикация на NuGet). Заслуги сообщившего — в advisory (если не requested otherwise).

## Область

- Все пакеты `Mediana.*` из этого репозитория
- Уязвимости зависимостей — тоже сюда (или через Dependabot alerts, если репозиторий уже подключён)

Вне области: DoS-атаки против приложений-потребителей без конкретного вектора через библиотеку; вопросы конфигурации пользовательских брокеров.
